# yt-paper

논문(DVCon, arXiv), 기술 서적, 블로그를 Claude로 요약하고, 관련 유튜브 영상과 연결한 뒤 GitHub Pages(MkDocs Material)에 자동으로 배포하는 CLI입니다.

## 1. 로컬 셋업

```bash
cd ~/works/yt-paper
sudo apt install python3.10-venv          # WSL에 venv가 없을 때 한 번만
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                      # ANTHROPIC_API_KEY 입력
git init -b main
```

## 2. 명령어

```bash
# 자료 추가 (로컬 PDF / arXiv / PDF URL / 웹 URL)
python -m src.cli add --source ~/works/dvcon/papers/2025/europe/DVConEU_2025_paper_100.pdf \
  --youtube "https://www.youtube.com/watch?v=xxxxxxxxxxx" --timestamp "04:15" --push
python -m src.cli add --source https://arxiv.org/abs/1706.03762

# 목록 파일로 한 번에 등록 (data/reading_list.csv)
python -m src.cli import --limit 3      # 3편만 시험
python -m src.cli import --push         # 전체

# 기존 자료에 영상 추가
python -m src.cli link --ref-id ref-20261018-a1b2 --youtube https://youtu.be/yyyyyyyyyyy --timestamp 05:30 --push

# 전체 페이지 재생성 / 검색
python -m src.cli rebuild --push
python -m src.cli list --category Verification --tag UVM

# 사이트 미리보기 (같은 Wi-Fi의 폰에서도 접속 가능)
mkdocs serve -a 0.0.0.0:8000
```

- 같은 출처(같은 PDF 파일명 또는 URL)를 다시 넣으면 요약을 다시 하지 않고 영상 연결만 추가합니다. 다시 요약하려면 `--refresh`를 붙이세요.
- `--youtube`는 여러 번 쓸 수 있습니다. `[url](url)`처럼 마크다운 링크 형태로 붙여 넣어도 영상 ID를 찾아냅니다.
- 커밋하지 않으려면 `--no-commit`을 붙이세요.
- `data/reading_list.csv` 열: `source`(PDF/웹 URL, 페이지에 표시되는 출처), `local_pdf`(있으면 본문을 이 파일에서 읽음), `youtube`(공백으로 여러 개), `title`, `type`, `timestamp`(시간 `04:15` 또는 메모·마크다운 링크). `import`는 이미 등록된 줄은 요약을 건너뛰고, 실패한 줄이 있어도 다음 줄로 계속합니다.

## 3. GitHub에 올리기 (최초 1회)

1. GitHub에 빈 저장소 `yt-paper`를 만들고 연결합니다: `git remote add origin <URL>`, `git add -A`, `git commit -m init`, `git push -u origin main`
2. Settings → Pages → Source를 **Deploy from a branch**, 브랜치를 **gh-pages / (root)**로 설정합니다. gh-pages 브랜치는 첫 배포가 끝난 뒤에 생깁니다.
3. Settings → Secrets and variables → Actions → **New repository secret**에서 `ANTHROPIC_API_KEY`를 등록합니다. 모바일에서 자료를 추가할 때 필요합니다.
4. 사이트 주소는 `https://<github-user>.github.io/yt-paper/` 입니다. `mkdocs.yml`의 `site_url`에도 이 주소를 넣어 두세요.

## 4. 모바일에서

**보기:** 폰 브라우저로 사이트 주소를 엽니다. 반응형 레이아웃, 다크 모드, 검색, 16:9 영상 임베드가 모두 동작합니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

**자료 추가 / 영상 연결:** 폰의 GitHub 앱이나 github.com에서 진행합니다. PC를 켜 둘 필요가 없습니다.
1. 저장소 → **Actions** → **Add resource (mobile)** → **Run workflow**
2. `source`에 arXiv, PDF URL, 블로그 URL을 넣습니다. 필요하면 `youtube`, `timestamp`도 채웁니다.
   - 영상만 연결하려면 `source`를 비우고 `ref_id`와 `youtube`를 넣습니다.
3. 실행하면 서버가 요약, 커밋, 배포까지 처리합니다. 1~3분 뒤 사이트에 반영됩니다.

로컬 PDF는 모바일에서 넣을 수 없습니다. PDF의 URL을 쓰세요. 예: `https://dvcon-proceedings.org/wp-content/uploads/....pdf`

## 5. 구조와 동작

- `data/index_dump.json`이 Git으로 관리하는 원본입니다. `data/archive.db`는 Git에서 제외되며, 없으면 실행할 때 JSON에서 자동으로 복원합니다. GitHub Actions도 이 방식으로 실행됩니다.
- DB에 변경이 생길 때마다 JSON을 자동으로 다시 저장합니다.
- `docs/` 아래의 생성 페이지에는 `<!-- generated by yt-paper -->` 표시가 붙습니다. 직접 수정해도 다시 생성할 때 덮어써집니다.

## 6. 명세서와 다르게 구현한 부분

- **모델:** 명세서의 `claude-3-5-sonnet-latest`는 2025-10-28에 서비스가 종료되었습니다. 그래서 기본값을 같은 Sonnet 계열의 현재 모델 `claude-sonnet-5-5`로 했고, `.env`의 `ANTHROPIC_MODEL`로 바꿀 수 있습니다.
- **구조화 출력:** 현재 Claude 모델은 `tool_choice`로 특정 툴을 강제 호출하는 방식을 400 오류로 거부합니다. 대신 Structured Outputs(`messages.parse(output_format=LLMExtractionResult)`)를 썼습니다. 응답 자체가 Pydantic 스키마로 제한되므로 "스키마 오류 원천 차단"이라는 목적은 그대로 만족합니다.
- **거절 시 폴백:** 안전 분류기가 요청을 거절하면 서버가 다른 모델로 자동 재시도하도록 서버측 폴백(`fallbacks="default"`)을 켜 두었습니다. 끄려면 `.env`에 `ANTHROPIC_FALLBACKS=off`를 넣으세요.
